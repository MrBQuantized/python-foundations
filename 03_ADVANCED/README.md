# 03 Advanced Python

This section explores advanced Python concepts that go beyond everyday programming. The focus is on understanding how Python works internally, writing more efficient and maintainable code, and becoming comfortable with the tools and techniques used in professional development.

Rather than treating these topics as isolated concepts, this section emphasizes understanding the underlying mechanisms and knowing when to apply them in real-world projects.

---

## Topics

### Concurrency

Learn techniques for running tasks concurrently and writing responsive applications.

Topics include:

* Threading
* Multiprocessing
* Asyncio
* Concurrent execution patterns

---

### Iterators

Understand Python's iteration model and build custom iterable objects.

Topics include:

* Iterator protocol
* `iter()` and `next()`
* Custom iterators
* Lazy evaluation
* Relationship between iterators and generators

---

### Unit Testing

Write reliable and maintainable software through automated testing.

Topics include:

* `unittest`
* `pytest`
* Test organization
* Fixtures
* Mocking
* Test-driven development (TDD)

---

## Goals

This section aims to:

* Understand advanced Python language features.
* Write efficient and maintainable code.
* Learn concurrency models and when to use them.
* Develop confidence in testing and debugging.
* Build a stronger foundation for backend development, automation, data science, and AI engineering.
